# Support

This is an independent, community project — not an official Anthropic
product, and not currently monitored by Anthropic support channels.

## Reporting an issue

Report issues on the project's GitHub issue tracker:
https://github.com/Shashankhs3/claude-code-coach/issues

When reporting an issue, please include:

- VS Code version (`Help > About`)
- Operating system
- Whether the Claude Code Coach desktop application was running
- The contents of the status bar item and the Coach panel at the time of
  the issue
- Any errors visible in **Help > Toggle Developer Tools > Console** while
  the extension is active

## Known limitation: desktop app dependency

**This extension does nothing on its own.** It requires the Claude Code
Coach desktop application to be running on the same machine — it is a
client, not a standalone tool. If you see `Coach: Offline` in the status
bar, that is very likely the correct, expected state (the desktop app
isn't running), not a bug in the extension. See the README's
[Troubleshooting](README.md#troubleshooting) section first.

## Other known limitations

See the README's [Known Limitations](README.md#known-limitations)
section for the current, honest list of what this beta does not yet do.
