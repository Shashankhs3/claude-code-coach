01 · The mechanism

The agent loop

Claude Code documented

Claude Code runs in a loop of reasoning and tool use — and everything that loop produces becomes context for what comes next. A file it reads, a command it runs, a search result: none of that disappears after the step that produced it. It's now part of what Claude is working from for the rest of the session. That single fact is the reason almost everything else in this workshop matters.

1

Prompt

You state a task — the first thing added to context.

2

Reason

Claude decides what to do next, given everything in context so far.

3

Act

It calls a tool — reads a file, runs a search, edits code, calls an MCP server.

4

Observe

The tool's result is appended to context, and the loop repeats from Reason.

Cycling automatically — hover to pause. Every full turn of this loop makes the working set bigger, never smaller, until something (you, or a session boundary) deliberately trims it.

02 · The resource you're actually managing

Context is not the same thing as tokens

Official Anthropic

Context is the model's full working set — not just your latest message. System instructions, tool definitions, CLAUDE.md and any Skills loaded, every file read so far, the whole conversation history, and every tool result all sit in it at once. Manage it for focus and relevance first — don't assume a local estimate tells you the exact billing math. Coach heuristic

03 · The interactive centerpiece

The anatomy of a good task

Claude Code documented

A good prompt reduces ambiguity — not necessarily length. Give direction where judgment matters; don't micromanage the execution. Six things tend to separate a task Claude can just start from one it has to guess its way through: a real goal, a scope, a hint at where to investigate, any constraints, a definition of done, and what output you actually want back.

04 · Before you touch anything

Search → narrow → read → modify

Claude Code documented

Search-first suits a narrow task — find the two relevant files, then read only those. A broad task can justify broad reading (a security audit, a comparative research question) — the point isn't "read less," it's relevance being a deliberate judgment call, not a default. Coach heuristic

Narrow task

"The login form accepts empty passwords" → search for the login handler → narrow to one or two files → read those → modify. Reading the whole auth module first adds nothing but noise.

Justified-broad task

"Security-review the auth module" → broad reading is the task. The Coach's own signal for this is careful not to flag a legitimately broad task just for its file count.

And tool output is context too: ask for a targeted result, not a full dump you'll filter yourself after the fact. Official Anthropic

05 · Ending, continuing, compacting

Session hygiene

Official Anthropic

Same coherent task → keep going. Different task → a fresh session usually serves you better, since unrelated history rarely helps the next thing. /clear resets context between unrelated tasks.

Same task, less baggage

/compact continues the same task with a lighter history — it does not erase your progress. It's only as useful as what you make sure survives it, so name what must carry forward: /compact focus on the auth refactor, drop the exploratory reads.

Different task entirely

Start over. Carrying yesterday's debugging session into today's unrelated feature work doesn't save time — it just makes the model sift through history that was never relevant to begin with.

06 · Pick the right tool for the job

Your four levers (and the fifth: just ask)

Coach heuristic

Tell me what you're dealing with, and this picks the lever:

Hook

Fires on real Claude Code events (PreToolUse, Stop, …) via settings.json. Guarantees an action happens; an instruction only asks for it.

Skill

A SKILL.md that packages a repeatable workflow so it's done consistently instead of re-explained every time.

Agent

A delegated specialist for independent work — trades full detail for an isolated, distilled summary back.

CLAUDE.md

Stated once, applies to every session — the place for durable project rules, not conditional or one-off detail.

Just the prompt

Most tasks are just this. Not everything deserves a Skill, an Agent, or a standing rule.

Rule to enforce → hook. Contextual know-how → Skill. Delegation → Agent. Always-on guidance → CLAUDE.md. This task → prompt.
07 · Reach and restraint

MCP, and how much rope to give it

Claude Code documented

MCP

MCP connects Claude to capabilities beyond file edits and shell commands. Check what's actually connected before assuming a capability is missing — and add servers deliberately, not by default. Every connected server is more context and more surface area, not a free lunch.

Permissions

Match the permission mode to what's actually at stake in the work in front of you. Never bypass a safety check purely for convenience — the cost of a bad auto-approved action is almost always higher than the ten seconds a confirmation costs you.

08 · The step people skip

Implementation is not completion

Claude Code documented

A change without a check is not yet a finished change. Give Claude a pass-or-fail condition, not just a description of the goal — "done when pytest tests/test_auth.py passes," not "done when it looks right."

10 · The tool this workshop leads to

Meet Claude Code Coach

Not a prompt checker — a workflow coach. Given what you're trying to accomplish, it tells you how to actually work with Claude Code: prompt scoping and rewriting, an Approach Advisor spanning prompt / environment / runtime evidence, Skill and Agent creation, and session-coherence and verification coaching. Local-first, fully offline, no AI API — every suggestion is regex/rule-based and fully explainable, and the in-app Context Efficiency Score is a local coaching heuristic, never presented as an official Anthropic metric.

How it talks about what it finds

Nothing is invented — every claim is a real file found on disk, or explicitly labeled as the Coach's own inferred signal:

DETECTEDAn actual Skill, Agent, CLAUDE.md, or MCP entry found on disk right now.
POSSIBLEYour prompt looks related to a DETECTED resource — confidence-rated, medium or high.
INFERREDNo real resource found, but a repeated pattern suggests one would help. Never "consider creating" something that already exists.
UNKNOWNNeither, or a specific scan item failed — surfaced as a scan warning, never guessed at.
